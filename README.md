# PHP-based Music Preferences Survey
This is My PHP-based Music Preferences Survey featuring 18 questions, using PHP, HTML, and CSS.
## Installation
1. Download or clone this GitHub repository.
2. Install and open MAMP or WAMP.
3. Place the project folder inside the MAMP `htdocs` directory.
4. Start the server in MAMP.
5. Open the project in your browser.
## Usage
Fill out the survey by answering all required questions.
